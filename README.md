For this project, I was able to make a simple and basic HTML site, containing a home and project page. The theme of the page was over PC builds and gaming.

### Challenges
The biggest challenge I went through was making sure that everything that was required was actually on the page, and written the correct way. Not being able to use CSS was a little bit of an issue as well, but it's safe to say I managed to do well on HTML styling.
